# Отчёт о скорости синтеза

Книга: «Некромант из Псковской губернии-6. Авантюрист», 21 глава, голос `kseniya`, модель `v5_ru`, 48 kHz, MP3 96 kbps.
Устройство: AMD Radeon RX 9060 XT (gfx1200), PyTorch 2.15.0+rocm10.0, ROCm/HIP 7.15.

## Прогон на GPU (cuda)

Итог: 21 глава, 7 ч 03 мин аудио (25 326 с).

Главы 2–21 записались за 562 с (9,4 мин). Вся книга в среднем синтезируется примерно в 43 раза быстрее реального времени (24 152 с аудио / 562 с).

Глава 1 частично пришла из кэша прошлого прерванного запуска, поэтому её отдельное время не замерено.

Первый запуск был медленнее из-за компиляции GPU-ядер и отсутствия базы MIOpen для gfx1200, это разовая стоимость.

Время каждой главы рассчитано по времени записи MP3-файла. Оно включает не только синтез, но и запись WAV-фрагментов и кодирование в MP3 через ffmpeg. Чистый синтез быстрее: для главы 13 он занял 6,6 с, а по записи файла прошло 15 с (см. ниже).

Скорость растёт от главы к главе: в начале сказываются прогрев и накопление тактовых частот GPU, в дальнейшем скорость стабильна около 45–50×.

## Сравнение CPU и GPU на одной главе

Глава 13: 712 с чистого аудио (770 с по записи файла, с учётом пауз), 94 фрагмента, одни и те же фрагменты. Замеряется только `synthesize`, прогрев сделан на первом фрагменте, до замера.

| Устройство | Загрузка модели, с | Синтез, с | Скорость (× реального времени) | На фрагмент, с |
|---|---:|---:|---:|---:|
| GPU (cuda) | 1.8 | 6.6 | 108 | 0.07 |
| CPU | 0.8 | 38.1 | 19 | 0.40 |

GPU быстрее примерно в 5,8 раза.

Оценка для всей книги (7 ч 03 мин аудио), только синтез: GPU ≈ 4 мин, CPU ≈ 23 мин. Это пересчёт по скорости из замера, а не отдельный прогон.

Разница между чистым синтезом главы 13 на GPU (6,6 с) и временем её записи (15 с) — это запись WAV-фрагментов и кодирование в MP3. В замере они не учитывались, отдельно я их не замерял. Поэтому по главам в таблице выше указана итоговая скорость пайплайна, а не только синтеза.
