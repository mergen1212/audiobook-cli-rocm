# ttsprodj — озвучивание книг на русском языке

Превращает книги (TXT, FB2, EPUB) в MP3 по главам. Речь синтезирует модель [Silero TTS](https://github.com/snakers4/silero-models) для русского языка на PyTorch. Вычисления идут на видеокарте AMD через ROCm; при необходимости можно работать на CPU.

## Требования

- Linux с драйвером `amdgpu`; доступ к `/dev/kfd` и `/dev/dri/renderD*` (обычно нужны группы `render` и `video`).
- Видеокарта AMD с поддержкой ROCm. Целевая конфигурация: Radeon RX 9060 XT (RDNA4, gfx1200).
- Python 3.12 (uv установит его сам при необходимости).
- `ffmpeg` с кодеком `libmp3lame`.

## Установка

```bash
uv sync                 # PyTorch ROCm 7.2 ставится с download.pytorch.org (см. pyproject.toml)
uv run ttsprodj check-gpu
```

Если `check-gpu` не видит видеокарту, проверьте `id` (группы `video` и `render`) и `ls -l /dev/kfd /dev/dri/renderD128`.

## Использование

```bash
# Главы книги и оценка длительности (без синтеза)
uv run ttsprodj info книга.epub

# Доступные голоса модели
uv run ttsprodj speakers

# Озвучивание: MP3 по главам в папку out/
uv run ttsprodj synth книга.epub -s xenia -o out/
```

Результат — файлы вида `out/001 - Глава 1.mp3`, `out/002 - ….mp3` и т. д.

Полезные опции `synth`:

| Опция | Описание |
|---|---|
| `-s, --speaker` | голос Silero (см. `speakers`) |
| `-m, --model` | модель Silero, по умолчанию `v5_ru` |
| `--device {auto,gpu,cpu}` | `auto` — GPU, если доступна, иначе CPU |
| `--sample-rate {24000,48000}` | частота дискретизации, по умолчанию 48000 |
| `--max-chars` | максимум символов в одном фрагменте синтеза (по умолчанию 400) |
| `--bitrate` | битрейт MP3 (по умолчанию 96k) |
| `--keep-cache` | не удалять WAV-кэш фрагментов |
| `--merge` | дополнительно склеить все главы в один MP3 `out/<название книги>.mp3` с метками глав (нужен `ffprobe`) |

### Прерывание и продолжение

Работу можно остановить (Ctrl+C) и запустить снова с теми же аргументами. Готовые главы пропускаются, а уже синтезированные фрагменты берутся из кэша `out/.cache`.

## Структура проекта

```
src/ttsprodj/
  books.py      чтение TXT/FB2/EPUB и разбиение на главы
  text.py       нормализация текста (числа, тире диалогов, проценты) и нарезка на фрагменты
  tts.py        загрузка модели Silero и синтез речи
  pipeline.py   сборка: фрагменты -> WAV-кэш -> MP3 главы
  audio.py      PCM, WAV, кодирование MP3 через ffmpeg
  device.py     выбор GPU/CPU и диагностика ROCm
  cli.py        командная строка
tests/          тесты (pytest)
```

Модель `v5_ru` скачивается автоматически в `models/` при первом запуске. Ударения и буква «ё» расставляются самой моделью.

## Ограничения

- PDF не поддерживается: конвертируйте книгу в EPUB, FB2 или TXT.
- Числа читаются количественными словами: «2» → «два». Порядковые числа («2-й») и склонение с числами не обрабатываются.
- Аббревиатуры и латиница читаются так, как их произносит модель; при необходимости правьте текст.
- Используйте только книги, на озвучивание которых у вас есть права.
